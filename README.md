# Task Modal (React + TypeScript)

Модальное окно для **создания и редактирования задач**, реализованное на **React + TypeScript**
с фокусом на **логику, доступность (a11y) и UX-детали**.

Компонент подходит для использования в **админ-панелях, CRM-системах и внутренних интерфейсах**.

---

## Возможности

* Управляемая форма (controlled inputs)
* Создание **и редактирование** задач в одном компоненте
* Поддержка статуса задачи: `default` / `active`
* Автофокус на поле названия при открытии модального окна
* Закрытие:

  * по клавише `Esc`
  * по клику на overlay
  * по кнопке закрытия
* Валидация дат:

  * дата окончания не может быть раньше даты начала
* Защита от повторной отправки формы
* Блокировка прокрутки страницы при открытой модалке
* Вертикальный скролл только внутри модального окна
* Полная адаптивность (mobile / tablet / desktop)
* Кнопка сохранения на всю ширину модального окна

---

## Архитектура и подход

* React Hooks:

  * `useState`
  * `useEffect`
  * `useCallback`
  * `useRef`
* **Single source of truth** для состояния формы
* Универсальный обработчик полей формы
* Минимальные и предсказуемые side-effects
* Семантическая HTML-разметка:

  * `header`
  * `form`
  * `footer`
* Accessibility (a11y):

  * `role="dialog"`
  * `aria-modal="true"`
  * `aria-labelledby`
  * корректное управление фокусом
* CSS Modules + БЭМ-нейминг
* Изоляция стилей и логики компонента
