# Task Modal (React + TypeScript)

Модальное окно для добавления задач, реализованное на React и TypeScript
с упором на логику, семантическую разметку и удобство пользователя.

Компонент предназначен для использования в админ-панелях и интерфейсах.

---

## Возможности

- Управляемая форма (controlled inputs)
- Добавление задачи через модальное окно
- Автофокус на поле названия при открытии
- Закрытие по `Esc`, клику на overlay и кнопке
- Валидация дат (дата окончания не раньше даты начала)
- Защита от повторной отправки формы
- Блокировка прокрутки страницы при открытой модалке
- Полная адаптивность (mobile / tablet / desktop)
- Кнопка сохранения на всю ширину модального окна

---

## Архитектура и подход

- React Hooks (`useState`, `useEffect`, `useCallback`, `useRef`)
- Single source of truth для состояния формы
- Минимальные side-effects
- Семантическая HTML-разметка (`header`, `main`, `footer`)
- Accessibility:
  - `role="dialog"`
  - `aria-modal`
  - `aria-labelledby`
- CSS Modules + БЭМ-нейминг
- Только вертикальный скролл внутри модалки
